# Python 数据分析

个人学习 Python 数据分析时写下的练习代码，围绕 **numpy、matplotlib、scipy** 三个库展开。

> 学习还在进行中，内容会陆续补充，本 README 等全部学完后再完善。

- GitHub：<https://github.com/wangfuhong666/python-data-analysis>
- Gitee：<https://gitee.com/wang_fuhong/python-data-analysis>

## 环境与依赖

- Python 3.13
- 依赖：

```bash
pip install numpy matplotlib scipy pillow
```

| 依赖 | 用途 |
| --- | --- |
| `numpy` | 数组与矩阵运算 |
| `matplotlib` | 数据可视化 |
| `scipy` | 科学计算 |
| `Pillow`（`PIL`） | 图片读取与保存 |

## 运行方式

```bash
python 01.py
```
